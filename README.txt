CANDY POP MANIA
Web-based match-3 starter project.

Run locally:
- Open index.html in Acode preview or a browser.
- Keep the assets folder beside index.html.
- Deploy the whole folder/repository to Vercel as a static site.

Files:
index.html, style.css, game.js
assets/images: original SavaCrush 1.1.1 PNG artwork
assets/sounds: original SavaCrush 1.1.1 MP3 sound effects

Note: This is a browser adaptation using the supplied artwork and sound files;
it is not a direct execution of the original Python/Pygame source.
